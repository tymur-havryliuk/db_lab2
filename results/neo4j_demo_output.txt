CRUD: створення вузлів і зв'язків (крок 1/3)
------------------------------------------------------------------------------
Пояснення: CREATE додає вузол Customer із тимчасовим id = -1 (мітка demo:true, потім видаляється).
Cypher:
  CREATE (c:Customer {id: -1, name: 'DEMO Замовник', tax_code: '00000000', demo: true})
  RETURN c.id AS id, c.name AS name, c.demo AS demo
Результат:
  id  name           demo
  --  -------------  ----
  -1  DEMO Замовник  True

CRUD: створення вузлів і зв'язків (крок 2/3)
------------------------------------------------------------------------------
Пояснення: Тимчасове місто, щоб не змінювати реальні дороги: MATCH знаходить Київ, CREATE додає вузол і ребро ROAD з властивостями.
Cypher:
  MATCH (kyiv:City {name: 'Київ'})
  CREATE (kyiv)-[r:ROAD {km: 10.0, hours: 1.0, demo: true}]->(d:City {id: -1, name: 'DEMO-місто', oblast: 'Київська', demo: true})
  RETURN kyiv.name AS від, d.name AS до, r.km AS km, r.hours AS hours
Результат:
  від   до          km    hours
  ----  ----------  ----  -----
  Київ  DEMO-місто  10.0  1.0

CRUD: створення вузлів і зв'язків (крок 3/3)
------------------------------------------------------------------------------
Пояснення: Зв'язок замовник -> місто: MATCH обох кінців, CREATE ребра LOCATED_IN.
Cypher:
  MATCH (c:Customer {id: -1}), (d:City {id: -1})
  CREATE (c)-[:LOCATED_IN]->(d)
  RETURN c.name AS замовник, d.name AS місто
Результат:
  замовник       місто     
  -------------  ----------
  DEMO Замовник  DEMO-місто

Найкоротший шлях за кількістю переїздів
------------------------------------------------------------------------------
Пояснення: Вбудований shortestPath (BFS) за ребрами ROAD без напрямку; довжина = кількість ребер.
Параметри: from=Київ, to=Одеса
Cypher:
  MATCH (a:City {name: $from}), (b:City {name: $to})
  MATCH p = shortestPath((a)-[:ROAD*..10]-(b))
  RETURN [n IN nodes(p) | n.name] AS маршрут, length(p) AS переїздів,
         reduce(s = 0.0, r IN relationships(p) | s + r.km) AS км_разом
Результат:
  маршрут                           переїздів  км_разом
  --------------------------------  ---------  --------
  [Київ, Здолбунів, Херсон, Одеса]  3          1354.4  

==============================================================================
Найкоротший шлях за кілометрами (власний Cypher, без GDS/APOC)
------------------------------------------------------------------------------
Пояснення: Перебираємо ВСІ прості шляхи довжиною 1..6, сумуємо km через reduce і беремо мінімум (ORDER BY ... LIMIT 1). Обмеження: це повний перебір (кількість шляхів росте як deg^довжина), тому глибина обмежена; шлях довший за межу не буде знайдено. Для великих графів потрібен Dijkstra з GDS.
Параметри: from=Київ, to=Одеса
Cypher:
  MATCH (a:City {name: $from}), (b:City {name: $to})
  MATCH p = (a)-[:ROAD*1..6]-(b)
  WITH p, reduce(s = 0.0, r IN relationships(p) | s + r.km) AS km
  ORDER BY km ASC
  LIMIT 1
  RETURN [n IN nodes(p) | n.name] AS маршрут, length(p) AS переїздів, km AS км_разом
Результат:
  маршрут                                         переїздів  км_разом
  ----------------------------------------------  ---------  --------
  [Київ, Біла Церква, Умань, Первомайськ, Одеса]  4          575.4

Досяжні міста за ≤ 2 переїздів
------------------------------------------------------------------------------
Пояснення: Перебір шляхів 1..2 від міста; min(length(p)) — найменша кількість переїздів до кожного міста.
Параметри: from=Ужгород
Cypher:
  MATCH p = (a:City {name: $from})-[:ROAD*1..2]-(b:City)
  WHERE b <> a
  WITH b, min(length(p)) AS hops
  RETURN hops AS переїздів, count(b) AS міст, collect(b.name)[..5] AS приклади
  ORDER BY hops
Результат:
  переїздів  міст  приклади                                              
  ---------  ----  ------------------------------------------------------
  1          4     [Мукачево, Борислав, Дрогобич, Стрий]                 
  2          15    [Івано-Франківськ, Львів, Чернігів, Мелітополь, Калуш]

Водії зі спільними замовниками
------------------------------------------------------------------------------
Пояснення: Беремо водія з найбільшою кількістю рейсів, шукаємо інших водіїв через спільного сусіда Customer (Driver-DROVE->Trip-FOR->Customer<-FOR-Trip<-DROVE-Driver) і рахуємо різних спільних замовників.
Cypher:
  MATCH (d1:Driver)-[:DROVE]->(t1:Trip)
  WITH d1, count(t1) AS рейсів
  ORDER BY рейсів DESC, d1.id
  LIMIT 1
  MATCH (d1)-[:DROVE]->(:Trip)-[:FOR]->(c:Customer)<-[:FOR]-(:Trip)<-[:DROVE]-(d2:Driver)
  WHERE d2 <> d1
  RETURN d1.full_name AS водій, d2.full_name AS колега, count(DISTINCT c) AS спільних_замовників
  ORDER BY спільних_замовників DESC, колега
  LIMIT 10
